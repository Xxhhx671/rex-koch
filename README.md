# Kofi — мессенджер

Локальный мессенджер с аккаунтами, личными и групповыми чатами, каналами и
полным набором привычных функций Telegram. Работает на вашем компьютере.

## Возможности

### Чаты
- Регистрация и вход (сессии в cookie, пароли — PBKDF2)
- Личные чаты, группы (переименование, участники, выход) и каналы с @ником
- Картинки, голосовые сообщения с выбором микрофона, аватары
- Статусы «доставлено» и «прочитано», индикатор «печатает…»
- Счётчики непрочитанных, обновление списка без перезагрузки
- Поиск людей по нику, имени и номеру телефона
- Прямые ссылки, **жирный**, *курсив* и `` `код` `` в тексте сообщений

### Сообщения
- **Ответы** — цитата с переходом к исходному сообщению
- **Редактирование** с меткой «изменено», удаление своих сообщений
- **Пересылка** в любой чат, автор источника сохраняется
- **Контекстное меню** (правый клик / долгое нажатие / кнопка «ещё»):
  ответить, копировать, переслать, закрепить, редактировать, удалить
- **Реакции** — до трёх своих на сообщение, повторный клик снимает
- **Опросы** — вопрос и до 10 вариантов, один голос, повторный клик снимает
- **Закреплённое сообщение** — панель сверху с переходом и снятием
- **Поиск по сообщениям** чата с подсветкой и переходом к находке
- **Черновики** — недописанный текст сохраняется и виден в списке чатов

### Организация
- **Папки чатов** — свои наборы чатов с переключением по вкладкам
- **Избранное** — личное облако для заметок и ссылок на себя
- **Тихий чат** — уведомления выключаются, значок в списке чатов
- **Закреплённые чаты** — всегда наверху списка
- **Исчезающие сообщения** — 1 час, день, неделя или месяц
- **Истории** — живут 24 часа, приватность (все / контакты / близкие друзья),
  просмотр с прогресс-барами, список зрителей у автора

### Профиль и безопасность
- Профиль: имя, ник, статус, телефон, адрес, часы работы, аватар
- **Приватность**: кто видит «последний визит» и телефон, кто может добавлять
  в чаты, поиск по номеру телефона
- **Двухэтапный вход** — код при входе на новое устройство
- **Устройства и сессии** — список входов с адресом и временем, завершение
- **Экспорт данных** — профиль, чаты и вся переписка одним файлом JSON
- **Удаление аккаунта** по паролю

### Интерфейс
- Тёмный адаптивный дизайн в чёрно-жёлтых тонах, значки — SVG (без эмодзи)
- Звук входящих и уведомления браузера по настройке
- Горячие клавиши: `Esc` — закрыть, `Ctrl+F` — поиск по чату, `Ctrl+K` — новый чат

В базе нет демо-аккаунтов: создаёте свой — и сразу работаете.

## Запуск

```powershell
.\start.ps1
```

Или вручную:

```powershell
py -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Затем откройте **http://127.0.0.1:8000**

## Технологии

| Слой     | Стек                        |
|----------|-----------------------------|
| API      | FastAPI + SQLAlchemy        |
| База     | SQLite (`social.db`)        |
| Фронтенд | Vanilla JS SPA + CSS        |

## Структура

```
app/
  main.py        точка входа, миграции, раздача фронтенда
  db.py          подключение к БД, включение внешних ключей
  models.py      модели: User, Chat, Message, Folder, Story, Reaction…
  security.py    хеши паролей, токены сессий
  helpers.py     зависимости, настройки, сериализация
  routes/
    auth.py      регистрация, вход, профиль, 2FA, сессии, экспорт
    chats.py     чаты, сообщения, ответы, правка, пересылка, поиск
    features.py  реакции, опросы, папки, черновики, истории, настройки
static/
  index.html     разметка SPA + SVG-значки
  app.js         клиентская логика и маршрутизация
  style.css      стили
  uploads/       загруженные изображения и голосовые
tests/
  smoke_test.py  сквозной тест API (183 проверки)
  cleanup_db.py  очистка базы от тестовых данных
social.db        база данных (создаётся при первом запуске)
```

## API

| Метод | Путь                                  | Описание                     |
|-------|---------------------------------------|------------------------------|
| POST  | `/api/register`, `/api/login`         | Регистрация и вход (с кодом 2FA) |
| GET   | `/api/me`                             | Профиль, настройки, 2FA      |
| PATCH | `/api/me`                             | Имя, ник, статус, телефон    |
| DELETE| `/api/me`                             | Удаление аккаунта            |
| POST  | `/api/me/2fa`                         | Включение и выключение 2FA   |
| GET   | `/api/sessions`                       | Устройства и входы           |
| DELETE| `/api/sessions/{token}`               | Завершить сессию             |
| GET   | `/api/export`                         | Выгрузка всех данных         |
| GET   | `/api/chats?folder_id=`               | Список чатов (с папкой)      |
| POST  | `/api/chats`, `/api/chats/group`      | Личный чат и группа          |
| POST  | `/api/channels`, `/api/chats/{id}/join` | Канал и подписка           |
| GET   | `/api/chats/{id}/messages?after=&before=` | История и опрос новых    |
| POST  | `/api/chats/{id}/messages`            | Отправка (`reply_to`, `poll`)|
| PATCH | `/api/messages/{id}`                  | Редактирование               |
| POST  | `/api/messages/{id}/forward`          | Пересылка                    |
| POST  | `/api/messages/{id}/reactions`        | Поставить реакцию            |
| POST  | `/api/messages/{id}/vote`             | Голос в опросе               |
| POST  | `/api/chats/{id}/pin`, `/mute`, `/auto-delete` | Закреп, тишина, исчезание |
| POST  | `/api/chats/{id}/draft`               | Черновик                      |
| GET   | `/api/chats/{id}/search?q=`           | Поиск по сообщениям          |
| GET   | `/api/saved`                          | Избранное                     |
| GET/POST/PATCH/DELETE | `/api/folders`               | Папки чатов                  |
| GET/POST/DELETE | `/api/stories`                    | Истории                       |
| GET   | `/api/settings`                       | Приватность, тема, звуки     |

Интерактивная документация: **http://127.0.0.1:8000/docs**

## Тесты

```powershell
py tests\smoke_test.py
```

Тест сам создаёт и удаляет тестовые данные — база остаётся чистой.
Если после упавших прогонов что-то осталось:

```powershell
py tests\cleanup_db.py
```
